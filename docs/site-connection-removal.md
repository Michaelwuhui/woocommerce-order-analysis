# 移除站点连接

系统设置中的“删除站点”移除该站点的 API 连接配置。站点退出连接列表，不再接受新的同步、商品编辑、克隆或库存推送操作。历史订单、同步记录、原站点编号、网址、负责人、国家、COD 配置及订单读取权限保留，历史报表与合伙人对账继续使用这些关联。

此前直接删除 `sites` 行会被 `sync_site_progress.site_id` 外键拒绝；清除历史进度或强行级联删除会丢失同步证据，删除站点身份也会改变历史订单的权限和报表范围。现在使用现有 `api_status='archived'` 标记已移除连接，清空该行 API 凭据并解除其商品 Master 路由，保留业务记录。无需新增数据库迁移。

删除前检查同步、克隆、库存写入及尚待核对的外部任务。存在这些任务或站点配置正在使用时，返回可重试的提示；应先等待或处理对应任务。创建后台任务与移除连接对同一站点行加锁，避免新任务绕过检查。已发送到外部网站的请求无法撤回，因此仍须先处理未确认结果。

重新添加相同网址并提供有效凭据可恢复原站点编号；只提交凭据时保留原负责人、国家和显示配置。已移除连接不能通过旧编辑窗口意外恢复，必须使用“添加站点”。此操作不会重新同步或自动修改历史订单。

发布验证使用合成站点和订单以及隔离 PostgreSQL 空库；真实站点的移除仍由管理员在页面上确认执行。
