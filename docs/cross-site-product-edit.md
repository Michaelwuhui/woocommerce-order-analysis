# 跨站产品编辑

在产品管理选择品牌、口味/关键词或全部产品，点击加载全部站点。结果陆续出现，可按负责人、站点、品牌、产品、口味、库存和发布状态组合筛选。站点失败或目录变化会提示未完成，已读取的结果保留，可重试未完成站点。

选择当前页或当前筛选的全部已加载结果。选中项在翻页、筛选后保留，操作区显示总数及筛选外的已选数量；执行前核对实际站点和商品范围。筛选本身不会修改商品或自动扩大已选范围。

| 操作 | 结果 |
| --- | --- |
| 行内编辑 / 保存全部修改 | 只提交发生变化的库存管理、数量、状态、原价或优惠价字段；翻页后未保存修改仍保留 |
| 批量改价 | 留空保持不变，明确清空优惠价才移除优惠；按各站原币种设置相同数值，不做汇率换算 |
| 批量设置库存 / 恢复库存 | 为选中简单商品和变体启用独立库存管理，设置指定数量 |
| 批量库存状态 / 售完 | 对选中商品设置有货、售完或缺货中；硬售完会关闭数量管理并设置售完 |
| 克隆 | 选中变体提升为该站父商品，按源站分组创建后台任务；可选变体、图片、目标状态及重复商品处理方式 |

商品沿用父库存时会标明继承关系。修改这类变体的库存，需要明确启用独立库存并填写数量，系统不会把父商品总库存自动复制到该变体。未转独立库存的售完、状态和数量操作会在写入前阻止，不会修改未选父商品或兄弟变体；价格仍可独立编辑。

执行前会读取当前商品，并核对加载时的 SKU、类型、属性及待修改字段。商品已被他人修改时保留草稿并报告冲突，需要刷新核对；站点负责人或权限变化也会阻止操作。库存操作按站点逐项执行，价格操作采用有限并发，每项都有独立状态和修改后的回读结果。停止操作只阻止后续提交，已提交的修改仍须核对，结果不明确时不会自动重放写入。

网站可能根据自身库存阈值和预订规则调整库存状态。库存联动元数据依据网站最终回读的实际状态核对，核心字段和联动字段一致后才显示已核验，不在本地猜测有货状态。

跨站编辑和克隆作用于明确选择的实际网站，现有单站编辑的 Master 路由保持原样。直接 API 缺少凭据的站点不能编辑，也不会自动改写其 Master。商品操作沿用库存同步写入保护；后台库存来源与网站插件仍可能在后续同步中更新库存，系统不会关闭既有同步配置。

克隆任务保存每件商品的进度，刷新后读取已有任务，不重复创建任务。选择“作为全新商品克隆”仍使用任务专属 SKU 并以草稿进入目标站。

父商品已创建但变体或图片未完成时显示部分失败及目标商品 ID，需核对已有目标商品。提交响应丢失时保留已知任务并锁定重复提交；管理员核对后台任务及目标商品后，才能人工解除提交锁。
